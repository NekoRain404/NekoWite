# NekoWite v1.0 核心体验 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付 NekoWite v1.0——一个 Tauri v2 桌面 MDX 所见即所得编辑器：应用壳（文件树/多标签/状态栏/设置）、工具栏 WYSIWYG 编辑、表格、YAML frontmatter 保留、三态视图（对照分屏/单独源码/单独渲染）、MDX/JSX 自定义组件节点、Markdown/MDX 往返保真、外部编辑热重载，以及用户插件骨架（vault/plugins/ 注册自定义 MDX 组件 + 工具栏按钮 + 命令）。

**Architecture:** pnpm workspace 单仓库，分三层——`packages/editor-core`（Milkdown + ProseMirror + remark 封装，含 MDX/JSX 自定义节点与序列化管道）、`packages/plugin-host`（vault 插件加载器 + definePlugin API）、`apps/desktop`（Tauri v2 + Vue3 + Pinia 应用壳，含三态视图控制器与文件服务）。功能以 feature-plugins 形式挂在 editor-core 注册表上。数据流：磁盘 `.md/.mdx` ⇄ Rust fs/Watcher ⇄ Pinia store ⇄ editor-core ⇄ 渲染；对照分屏是同一 doc 的两个投影，靠 store 单向数据流同步。

**Tech Stack:** pnpm workspace · Tauri v2 (Rust) · Vue 3 + TypeScript · Pinia · Milkdown v7（ProseMirror + remark）· vitest · Playwright · GitHub Actions CI。

## Global Constraints

- 包管理器必须为 **pnpm**（已装 11.x）。Node ≥ 22。
- Vue `^3.5`，Pinia `^3`，TypeScript `~5.9`，Vite `^7`，Vitest `^3`。
- Tauri：`@tauri-apps/api ^2`、`@tauri-apps/cli ^2`、Rust `tauri = "2"`、`tauri-plugin-fs = "2"`、`notify = "7"`、`serde = { version = "1", features = ["derive"] }`、`tokio = { version = "1", features = ["full"] }`。
- Milkdown：`@milkdown/core ^7`、`@milkdown/preset-commonmark ^7`、`@milkdown/preset-gfm ^7`、`@milkdown/vue ^7`、`@milkdown/utils ^7`、`@milkdown/plugin-listener ^7`、`@milkdown/plugin-history ^7`。若安装时该 major 已不可用，升级到可用 major 并同步更新本计划中的 import 与 API 名。
- MDX 管线：`remark`、`remark-gfm`、`remark-frontmatter`、`unified`、`@mdx-js/mdx`（序列化参考）均为依赖。
- 所有代码 TypeScript 严格模式；不得添加未使用变量/导入（ESLint + oxlint 把关）。
- 文件名/包名：应用包名 `nekowite`，npm 包 `@nekowite/editor-core`、`@nekowite/plugin-host`。
- 注释仅限必要 JSDoc；不写中文注释（代码与提交信息用英文，文档用中文）。
- 每个任务结束必须：跑测试/类型检查/lint 全绿，然后提交 git。
- 平台目标：先保证 Linux + WebKitGTK 可用；Windows/macOS 不阻塞。

- [ ] **Step 3: 实现 editor.ts**

`packages/editor-core/src/editor.ts`：

```ts
import { Editor, rootCtx } from '@milkdown/core'
import { commonmark } from '@milkdown/preset-commonmark'
import { gfm } from '@milkdown/preset-gfm'
import { listener, listenerCtx } from '@milkdown/plugin-listener'
import { history } from '@milkdown/plugin-history'
import type { MilkdownPlugin } from '@milkdown/core'
import type { EditorView } from '@milkdown/prose/view'

export const basicPlugins: MilkdownPlugin[] = [commonmark, gfm, history, listener]

export interface NekoEditor {
  open(content: string): void
  save(): string
  getView(): EditorView
  onContentChange(cb: () => void): () => void
}

export function createEditor(target: HTMLElement, options: { plugins?: MilkdownPlugin[] } = {}): NekoEditor {
  const plugins = options.plugins ?? basicPlugins
  let view: EditorView | null = null
  const changeHandlers = new Set<() => void>()

  const editor = Editor.make()
    .config((ctx) => {
      ctx.set(rootCtx, target)
    })
    .config((ctx) => {
      ctx.get(listenerCtx).markdownUpdated((_update, _prev) => {
        changeHandlers.forEach((h) => h())
      })
    })
    .use(plugins)
    .create()
    .then((created) => {
      view = created.action((ctx) => ctx.get(editorViewCtx))
    })

  return {
    open(content: string) {
      editor.then((created) => {
        created.action((ctx) => {
          ctx.get(editorViewCtx).dispatch(
            ctx.get(editorViewCtx).state.tr.replaceWith(0, ctx.get(editorViewCtx).state.doc.content.size, ctx.get(parserCtx)(content)),
          )
        })
      })
    },
    save() {
      return view?.state ? editorMarkdown(view) : ''
    },
    getView() {
      return view as EditorView
    },
    onContentChange(cb: () => void) {
      changeHandlers.add(cb)
      return () => changeHandlers.delete(cb)
    },
  }
}

function editorMarkdown(view: EditorView): string {
  return '@milkdown' // 占位：Task 3 替换为序列化管道
}
```

> 说明：`editorViewCtx`、`parserCtx` 来自 `@milkdown/core`；`editorMarkdown` 的序列化在 Task 3 用统一管道实现。Milkdown 的 `.action()` 是异步生效，测试断言前需等待 `editor.open` 的 promise 完成；上述测试在 happy-dom 下若时序不稳，`save` 改为返回可等待的 API 或在测试中 `await new Promise(r => setTimeout(r, 0))`。

`packages/editor-core/src/serialize.ts`：

```ts
import { unified } from 'unified'
import remarkParse from 'remark-parse'
import remarkGfm from 'remark-gfm'
import remarkFrontmatter from 'remark-frontmatter'
import remarkStringify from 'remark-stringify'
import type { Root } from 'mdast'

const processor = unified()
  .use(remarkParse)
  .use(remarkGfm)
  .use(remarkFrontmatter, ['yaml'])
  .use(remarkStringify, { bullet: '-', emphasis: '*', strong: '**', fences: true })

export function parseMarkdown(md: string): Root {
  return processor.parse(md)
}

export function serializeMarkdown(root: Root): string {
  return processor.stringify(root)
}

export function roundTrip(md: string): string {
  return serializeMarkdown(parseMarkdown(md))
}

export function escapeMdxText(text: string): string {
  return text.replace(/</g, '&lt;').replace(/\{/g, '&#123;')
}
```

> 说明：`remark-stringify` 需加入 `packages/editor-core/package.json` 依赖（`^11`）。frontmatter 经 `remark-frontmatter` 解析为 `yaml` 节点，stringify 时原样输出。

```ts
export interface MdxComponentAttrs {
  name: string
  props: Record<string, string>
  children: string
}

export const mdxComponent = createNode<'block', MdxComponentAttrs>((ctx) => ({
  id: 'mdxComponent',
  schema: () => ({
    group: 'block',
    content: 'inline*',
    atom: true,
    attrs: {
      name: { default: 'Component' },
      props: { default: {} as Record<string, string> },
      children: { default: '' },
    },
    parseDOM: [{ tag: 'div[data-mdx-component]' }],
    toDOM: (node) => {
      const { name, children } = node.attrs
      const el = document.createElement('div')
      el.setAttribute('data-mdx-component', name)
      el.textContent = children
      return el
    },
  }),
}))

export function mdxComponentToMarkdown(attrs: MdxComponentAttrs): string {
  const { name, props, children } = attrs
  const propStr = Object.entries(props)
    .map(([k, v]) => ` ${k}="${escapeMdxText(v)}"`)
    .join('')
  if (!children) return `<${name}${propStr} />`
  return `<${name}${propStr}>\n\n${children}\n\n</${name}>`
}

export function insertMdxComponent(view: import('@milkdown/prose/view').EditorView, attrs: MdxComponentAttrs): void {
  const { state } = view
  const node = state.schema.nodes.mdxComponent.create(attrs)
  view.dispatch(state.tr.replaceSelectionWith(node))
}
```

```ts
import type { Component } from 'vue'

export interface ToolbarItem { id: string; label: string; run: () => void }
export interface EditorCommand { id: string; run: () => void }
export interface RegistrationBatch {
  components?: Record<string, Component>
  toolbar?: ToolbarItem[]
  commands?: EditorCommand[]
}

export class DuplicateRegistrationError extends Error {}

const commands = new Map<string, EditorCommand>()
const components = new Map<string, Component>()
const toolbar: ToolbarItem[] = []

export function registerCommand(cmd: EditorCommand): void {
  if (commands.has(cmd.id)) throw new DuplicateRegistrationError(`command ${cmd.id} already registered`)
  commands.set(cmd.id, cmd)
}
export function getCommand(id: string): EditorCommand | undefined {
  return commands.get(id)
}
export function registerComponent(name: string, component: Component): void {
  if (components.has(name)) throw new DuplicateRegistrationError(`component ${name} already registered`)
  components.set(name, component)
}
export function getComponent(name: string): Component | undefined {
  return components.get(name)
}
export function registerToolbar(item: ToolbarItem): void {
  toolbar.push(item)
}
export function getToolbar(): ToolbarItem[] {
  return [...toolbar]
}
export function registerAll(batch: RegistrationBatch): void {
  for (const [name, comp] of Object.entries(batch.components ?? {})) registerComponent(name, comp)
  for (const item of batch.toolbar ?? []) registerToolbar(item)
  for (const cmd of batch.commands ?? []) registerCommand(cmd)
}
```

```rust
use std::path::{Path, PathBuf};

#[derive(Serialize, Clone)]
pub struct FileEntry {
    pub name: String,
    pub path: String,
    pub is_dir: bool,
    pub is_mdx: bool,
}

pub fn is_mdx_path(p: &str) -> bool {
    let path = Path::new(p);
    let is_dot_dir = path.components().any(|c| c.as_os_str() == "node_modules");
    if is_dot_dir { return false; }
    matches!(path.extension().and_then(|e| e.to_str()), Some("mdx") | Some("md") | Some("markdown"))
}

pub fn sanitize_path(p: &str) -> Result<PathBuf, String> {
    let path = Path::new(p);
    if path.is_absolute() || path.components().any(|c| c.as_os_str() == "..") {
        return Err("path escapes workspace".into());
    }
    Ok(path.to_path_buf())
}
```

```rust
    std::fs::read_to_string(&p).map_err(|e| e.to_string())

    let p = fs::sanitize_path(&path).map_err(|e| e.to_string())?;
    std::fs::write(&p, content).map_err(|e| e.to_string())

#[tauri::command]
fn list_dir(path: String) -> Result<Vec<fs::FileEntry>, String> {
    let p = fs::sanitize_path(&path).map_err(|e| e.to_string())?;
    let mut out = vec![];
    let entries = std::fs::read_dir(&p).map_err(|e| e.to_string())?;
    for entry in entries.flatten() {
        let p2 = entry.path();
        let name = p2.file_name().and_then(|n| n.to_str()).unwrap_or("").to_string();
        let is_dir = p2.is_dir();
        let path_str = p2.to_string_lossy().to_string();
        if is_dir || fs::is_mdx_path(&path_str) {
            out.push(fs::FileEntry { name, path: path_str, is_dir, is_mdx: !is_dir && fs::is_mdx_path(&path_str) });
        }
    }
    out.sort_by(|a, b| (b.is_dir as u8).cmp(&(a.is_dir as u8)).then(a.name.cmp(&b.name)));
    Ok(out)
}
```

```rust
use notify::{Watcher, RecursiveMode, RecommendedWatcher};

#[tauri::command]
fn watch_folder(app: tauri::AppHandle, path: String) -> Result<(), String> {
    let p = fs::sanitize_path(&path).map_err(|e| e.to_string())?;
    let mut watcher = RecommendedWatcher::new(
        move |res: Result<notify::Event, notify::Error>| {
            if let Ok(event) = res {
                for path in event.paths {
                    let _ = app.emit("fs-change", serde_json::json!({
                        "path": path.to_string_lossy(),
                        "kind": format!("{:?}", event.kind),
                    }));
                }
            }
        },
        notify::Config::default(),
    )
    .map_err(|e| e.to_string())?;
    watcher.watch(&p, RecursiveMode::Recursive).map_err(|e| e.to_string())?;
    std::mem::forget(watcher);
    Ok(())
}
```

```ts
import { defineStore } from 'pinia'
import { ref, computed } from 'vue'
import { fsService } from '../services/fs'

export interface OpenTab {
  id: string
  path: string | null
  content: string
  savedContent: string
  dirty: boolean
}

let seq = 0
const nextId = () => `tab-${++seq}`

export const useTabsStore = defineStore('tabs', () => {
  const tabs = ref<OpenTab[]>([])
  const activeId = ref<string | null>(null)
  const activeTab = computed(() => tabs.value.find((t) => t.id === activeId.value) ?? null)

  async function openTab(path: string | null, initial = ''): Promise<void> {
    let content = initial
    if (path) content = await fsService.read(path)
    const tab: OpenTab = { id: nextId(), path, content, savedContent: content, dirty: false }
    tabs.value.push(tab)
    activeId.value = tab.id
  }

  function closeTab(id: string): void {
    const i = tabs.value.findIndex((t) => t.id === id)
    if (i < 0) return
    tabs.value.splice(i, 1)
    if (activeId.value === id) activeId.value = tabs.value[i]?.id ?? tabs.value[i - 1]?.id ?? null
  }

  function setActive(id: string): void { activeId.value = id }
  function markDirty(id: string): void {
    const t = tabs.value.find((x) => x.id === id)
    if (t) t.dirty = true
  }

  async function saveActive(): Promise<void> {
    const t = activeTab.value
    if (!t || !t.path) return
    await fsService.write(t.path, t.content)
    t.savedContent = t.content
    t.dirty = false
  }

  async function reloadFromDisk(id: string): Promise<void> {
    const t = tabs.value.find((x) => x.id === id)
    if (!t || !t.path) return
    t.content = await fsService.read(t.path)
    t.savedContent = t.content
    t.dirty = false
  }

  return { tabs, activeId, activeTab, openTab, closeTab, setActive, markDirty, saveActive, reloadFromDisk }
})
```

```ts
import { createNode } from '@milkdown/utils'

export function tableMarkdown(rows: number, cols: number): string {
  const header = `| ${Array.from({ length: cols }, (_, i) => String.fromCharCode(97 + i)).join(' | ')} |`
  const sep = `| ${Array.from({ length: cols }, () => '-').join(' | ')} |`
  const body = Array.from({ length: rows - 1 }, (_, r) => `| ${Array.from({ length: cols }, (_, c) => String(r + 1 + c * 0)).join(' | ')} |`).join('\n')
  return body ? `${header}\n${sep}\n${body}` : `${header}\n${sep}`
}

export function insertTable(view: EditorView, rows: number, cols: number): void {
  const { state } = view
  const node = state.schema.nodes.table.create(
    null,
    // 按 gfm 表格 schema 构造 header/body row nodes；本任务先经 markdown 路径：
  )
  view.dispatch(state.tr.replaceSelectionWith(node))
}

export const tableFeaturePlugin: MilkdownPlugin[] = []
```

```ts
import type { PluginDefinition, PluginMeta } from './types'

export type LoadResult =
  | { ok: true; id: string; meta: PluginMeta; definition: PluginDefinition }
  | { ok: false; id: string; error: string }

type DynamicImport = (specifier: string) => Promise<{ default?: PluginDefinition }>

export async function loadPlugin(meta: PluginMeta, dynamicImport: DynamicImport): Promise<LoadResult> {
  try {
    const mod = await dynamicImport(meta.main)
    if (!mod.default) return { ok: false, id: meta.id, error: 'plugin has no default export' }
    return { ok: true, id: meta.id, meta, definition: mod.default }
  } catch (err) {
    return { ok: false, id: meta.id, error: err instanceof Error ? err.message : String(err) }
  }
}
```

`packages/plugin-host/src/runtime.ts`：

```ts
import { registerAll, getToolbar, getCommand, getComponent, type ToolbarItem, type EditorCommand } from '@nekowite/editor-core'
import type { LoadResult } from './loader'

const active = new Map<string, { def: import('./types').PluginDefinition; registeredComponents: string[]; registeredCommands: string[] }>()

export async function activatePlugin(result: LoadResult): Promise<{ ok: boolean; id: string; error?: string }> {
  if (!result.ok) return { ok: false, id: result.id, error: result.error }
  const { id, definition } = result
  const registeredComponents: string[] = []
  const registeredCommands: string[] = []
  try {
    if (definition.components) {
      for (const name of Object.keys(definition.components)) {
        // 直接经 registerAll 会整体回滚困难：改为逐个注册并记录
        registerAll({ components: { [name]: definition.components[name] } })
        registeredComponents.push(name)
      }
    }
    if (definition.commands) {
      for (const cmd of definition.commands) {
        registerAll({ commands: [cmd] })
        registeredCommands.push(cmd.id)
      }
    }
    if (definition.toolbar) registerAll({ toolbar: definition.toolbar })
    definition.onLoad?.({ id, name: definition.name ?? id, insertComponent: (name) => {
      const c = getComponent(name)
      if (!c) throw new Error(`component not found: ${name}`)
    } })
    active.set(id, { def: definition, registeredComponents, registeredCommands })
    return { ok: true, id }
  } catch (err) {
    for (const name of registeredComponents) { /* 从注册表移除 */ }
    for (const cmdId of registeredCommands) { /* 从注册表移除 */ }
    return { ok: false, id, error: err instanceof Error ? err.message : String(err) }
  }
}
```

> 说明：editor-core 的 registry 当前只支持「增」，回滚需要「删」。为支持回滚，Task 12 需给 registry 增加 `unregisterCommand(id)`、`unregisterComponent(name)`、`unregisterToolbar(id)` 三个函数（并在 registry.test.ts 补测试）。这是 Task 12 的一部分，确保 `deactivatePlugin`/回滚可测。

`deactivatePlugin(id)`：取 `active.get(id)`，逐个 unregister，调 `onUnload`，`active.delete(id)`。

- [ ] **Step 2: 确认失败 → 实现 errors.ts + Toast + ConflictDialog**

`errors.ts`：

```ts
export type ConflictDecision = 'reload' | 'keep' | 'ask' | 'none'
export function decideConflict(input: { dirty: boolean; hasDiskChange: boolean }): ConflictDecision {
  if (!input.hasDiskChange) return 'none'
  if (!input.dirty) return 'reload'
  return 'ask'
}

const listeners = new Set<(msg: string) => void>()
export function notifyError(message: string): void { listeners.forEach((l) => l(message)) }
export function onNotify(cb: (msg: string) => void): () => void { listeners.add(cb); return () => listeners.delete(cb) }
```
