# 笔记卡片右键菜单设计

## 背景

`NoteCard.vue` 当前只支持左键打开和收藏按钮。文件树已经有重命名、删除等菜单，但两处操作逻辑分散。用户在笔记列表中右键具体笔记时，需要能对“被右键的目标笔记”执行操作，而不是误作用于当前活动标签页。

本设计仅覆盖笔记列表卡片（包括内容搜索结果是否纳入由实施计划决定）；左侧文件树继续保留其新建文件夹/文件、重命名、删除菜单。

## 目标

右键笔记卡片显示以下菜单项：

1. 打开
2. 收藏或取消收藏（根据当前状态切换文案）
3. 重命名
4. 导出 HTML
5. 导出 PDF
6. 删除

菜单使用现有 `ContextMenu.vue` 和 lucide 图标，删除项使用现有 danger 样式。菜单关闭、Esc、点击外部、视口变化和键盘导航沿用通用组件行为。

## 关键行为

### 目标上下文

`NoteListPanel` 保存 `{ x, y, path }`，打开菜单时记录右键卡片的绝对路径。后续所有操作只读取该 `path`，不能依赖 `tabs.activeTab`。执行“打开”时调用现有 `tabs.openTab(path)` 并将其设为活动标签。

### 收藏

调用 `documentList.toggleFavorite(path)`。菜单文案和图标根据 `documentList.isFavorite(path)` 实时计算。操作后若当前筛选为“收藏”，列表由现有 store 过滤逻辑更新。

### 重命名

复用文件树已验证的 `moveNote`/`renameEntry` 路径迁移流程，至少保证：

- 先 `flushEdits()`，避免编辑器 debounce 内容被覆盖；
- 笔记旁的 `<basename>_assets` 随笔记移动；
- 打开的标签路径和引用在成功后同步；
- 冲突、非法名称、后端失败均显示现有错误通知，不留下半更新的卡片；
- 重命名对话框沿用现有 inline/modal 输入校验，不允许空名或路径分隔符。

如果抽取共享服务会扩大范围，第一版可在 `NoteListPanel` 复用服务接口而不复制底层迁移算法。

### 导出

导出必须读取右键目标的最新内容：

- 若目标有打开标签，使用该标签内容；若目标是活动标签，先 `flushEdits()`；
- 若目标未打开，从 `vaultSession.noteContent(path)` 或等价 fs 读取；
- HTML 调用现有 `exportHtml`，默认文件名使用 `exportBaseName(path) + '.html'`；
- PDF 调用现有 `exportToPdf`，标题使用目标笔记名；
- 传入 `notePath: path`，确保附件解析相对于目标笔记，而不是当前活动笔记；
- 复用现有导出设置（frontmatter、纸张、方向）和错误通知；
- 取消保存对话框时不提示错误；
- 当前 HTML 导出受 vault-confined 写入限制，若用户选择 vault 外路径，应沿用 `error.exportOutsideVault`，不得静默失败。

ContextMenu 暂不增加二级 submenu；HTML/PDF 作为两个带分隔线的平面菜单项，保持现有组件能力和键盘可达性。

### 删除

删除前显示确认。默认遵循 `appearance.confirmBeforeDelete`：

- 开启时展示现有确认对话框；
- 关闭时一次菜单选择直接执行删除；
- 若目标已打开，调用 `tabs.deleteTabFile(tab.id)`；
- 若未打开，调用 `deleteNoteWithAssets`，同时删除笔记及其 `_assets` 目录；
- 删除成功后关闭相关标签、刷新文档索引/列表并修剪收藏与最近记录；
- 重复点击必须由路径级 in-flight guard 防止重复删除；
- 失败时显示现有删除失败通知，菜单和确认状态复位。

## 非目标

- 不新增复制笔记、复制路径、在资源管理器中显示、批量操作。
- 不改变现有文件树菜单语义。
- 不修改 accent 色和主题基础色。
- 不把导出动作绑定到当前活动标签。

## 可访问性与交互

- 卡片监听 `contextmenu.prevent`，不影响左键打开和收藏按钮。
- 右键菜单项具有现有 `role="menuitem"`、禁用态和图标占位。
- 右键打开菜单后焦点进入首个可用菜单项；Esc 返回卡片或安全焦点。
- 删除项使用 `danger`，其余项目保持普通样式。

## 验收标准

- 对非活动笔记右键后，重命名、导出、删除均作用于该笔记。
- 对未打开笔记导出成功，附件相对路径正确。
- 对活动且有未提交编辑的笔记导出包含最新文本。
- 删除笔记不会遗留 `_assets`，不会留下指向已删除路径的收藏/标签。
- 重命名后列表、打开标签和收藏路径一致。
- 右键菜单可用鼠标、Esc、上下箭头和 Enter 操作。
