# NekoWite 0.99 Beta

这是 NekoWite 的首个 Linux 预览版本，内部版本号为 `0.99.0-beta.1`。

## 本次预览

- 提供 Arch 完全版/ACP 包、deb、rpm、ACP 单文件 ELF，以及自带和不带 OpenCode 的两种 AppImage（Linux x86_64）。
- 支持 ACP 自动扫描、手动注册、权限确认和启动诊断。
- 支持基于 Git 的云同步，以及基于 SSH/sshfs 的远程工作区入口。
- 收束设置、侧边栏抽屉、启动遮罩和编辑器交互，统一发布文档。

## 已知限制

- 构建尚未签名，也没有自动更新通道。
- 目前只发布 Linux x86_64；真实 ACP、WebKitGTK 和远程工作区仍建议按用户环境验收。
- 完全版随附 OpenCode 运行时；ACP 版直接调用用户本机已安装的 Agent。
- ACP 单文件 ELF 仍依赖系统 GTK / WebKitGTK；完全版便携程序需与 OpenCode 文件放在同一目录。

## 下载与校验

Arch 用户按需安装 `nekowite-full`（自带 OpenCode）或 `nekowite`（ACP）；两者不能同时安装。Deb 和 RPM 当前是完全版。AppImage 可选完整版或文件名带 `-acp` 的精简版。便携完全版须下载 `nekowite_0.99.0-beta.1_x64` 和 `opencode`，放在同一目录；`nekowite-acp_0.99.0-beta.1_x64` 是独立的 ACP ELF。AppImage 和 ELF 下载后需添加执行权限。
