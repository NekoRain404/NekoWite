# 用户指南

> 面向第一次使用 NekoWite 的写作者，以当前 Linux 桌面版为准。界面为简体中文；文中名称与设置面板里的实际标签一致。

## 1. 第一次打开

1. 启动后会看到「欢迎使用 NekoWite」，点「打开文件夹」选择一个文件夹（新建一个空文件夹也可以）——它就成为你的**知识库**（vault）。
2. 笔记、附件、模板、引用文献都放在这个文件夹里；用其它编辑器改动过的文件在 NekoWite 里会自动重载。
3. 换个知识库：设置 → 常规 →「知识库」（切换会关闭当前所有打开的文档）。

## 2. 界面速览

- 顶部标题栏：收起/展开侧栏、最小化/最大化/关闭，中间显示当前笔记标题与路径。
- 左侧第一栏：快捷操作（新建每日笔记、从模板新建）与导航（文件夹 / 全部笔记 / 最近 / 收藏 / 未分类 / 图谱 / 附件 / 索引 / 云同步），下面依次是标签、引用文献、回收站。知识库名称右侧的抽屉按钮可将本栏收起为图标导航，再点一次展开；笔记列表继续显示。文件夹菜单可以添加 SSH 远程工作区。
- 左侧第二栏：顶部的模式切换有七个——「笔记 / 大纲 / 链接 / 引用文献 / 历史版本 / 文档属性 / 统计」（后四个原先在右侧信息栏，现在并入这一栏；七个按钮都只有图标，名称在悬停提示与读屏标签里）；「笔记」模式下有搜索框、排序（修改时间 / 标题 / 文件名）、内容搜索开关与索引状态；点左侧的图谱 / 附件会把这一栏切换到对应面板，「索引」目前只有「即将支持」的占位（索引状态在笔记列表上方）。
- 中间：文档标签页与编辑器；编辑工具栏在打开文档后常驻编辑区上方，选中文字或把光标放进段落并不会让它出现或消失（点选浮动图片时出现在图片旁的是另一个「图片工具栏」）。
- 右侧信息栏：只有「AI」一个页签。这个栏默认显示的是**智能体面板**（可在其中「回到聊天面板」切回聊天）；大纲、引用文献、历史版本、文档属性与统计都在左侧第二栏的模式切换里；统计列出词、字符、段落、图片、引用、阅读时间与任务。
- 底部状态栏：词数、字符数、阅读时间、任务完成度、保存状态（保存中… / 未保存 / 已保存 / **保存失败**）；右侧是视图切换、信息栏开关与设置。

## 3. 新建与编辑笔记

- 新建：文件树的「新建文件 / 新建文件夹」、标签栏上的「新建文档」，或侧栏的「新建每日笔记」「从模板新建」。
- 命名规则：名称不能为空、不能以 `.` 开头、不能包含 `/`，同名会被拒绝。
- 直接输入即可写作（所见即所得）；输入 `#` 到 `######` 生成标题层级，左侧第二栏切到「大纲」即可跳转。
- 保存：`Ctrl+S`；默认每 15 秒自动保存（设置 → 编辑器 →「自动保存间隔」可选关闭 / 5 / 15 / 30 / 60 秒，另有「失焦自动保存」）。
- 未命名文档第一次保存时会弹出保存对话框，让你选择文件名与位置（限知识库内）。
- 删除：右键 →「删除」（把笔记移入回收站，可在设置里开启「删除前二次确认」）。
- 外部修改：如果文件被应用之外的程序改过，会弹出「文件已在外部被修改」，可选「以磁盘为准（放弃本地）」「保留本地」或「稍后再说」。

## 4. 编辑工具栏

打开文档后，编辑区上方常驻这一栏工具栏（关闭标签页或没有打开的文档时随之消失），按钮作用于选中的文字或光标所在处：

- 标题（可插入 标题 1–6）、加粗、斜体、删除线、行内代码
- 链接、图片
- 无序列表、有序列表、任务列表、引用、代码块、分隔线
- 插入 MDX 组件、插入数学公式（可视化编辑 `$…$` / `$$…$$`）、插入表格、插入 Callout、插入 FloatBox
- ✨（AI 菜单）：AI 改写 / 润色 / 翻译，作用于选中的文字

插入图片：直接粘贴或拖入编辑器，图片会保存到**这篇笔记旁边**的 `<笔记名>_assets/` 目录（笔记还没保存时先暂存在 `.tmp/`，保存后再移入），并在正文里插入引用。左侧「附件」列出的是知识库的 `attachments/` 目录——应用自己插入的图片（例如 AI 生成的 SVG）按年月放在那里，**粘贴进笔记的图片不会出现在这个列表里**；列表里的条目可以「插入到文档」「复制相对路径」或删除。

## 5. 三种视图

- **渲染**：所见即所得（默认视图可以在设置 → 编辑器里改）。
- **源码**：Markdown 源码编辑，可开启「源码行号」「源码自动换行」；`Ctrl+F` 打开查找与替换（区分大小写 / 全字匹配 / 正则表达式 / 全部替换）。
- **对照**：源码与渲染左右分屏，拖动中间分隔条调整比例；可开启「分屏滚动同步」。
- 切换方式：状态栏右下角的「源码 / 渲染 / 对照」，或设置里的「打开文档时默认视图」。

## 6. 搜索

- **命令面板**：`Ctrl+K`，搜索命令或文件；「命令」组执行编辑命令（标题、加粗、插入表格等），「文件」组直接打开笔记；回车执行、Esc 关闭。
- **按名称搜索**：笔记列表顶部搜索框，匹配标题、文件名与路径；右侧按钮切换排序。
- **内容搜索**：点搜索框右侧的搜索按钮打开「内容搜索」，输入关键词会在**正文**里查找并给出匹配片段与数量。
- 内容搜索依赖索引：笔记列表上方会显示索引状态（正在建立索引… / 索引已是最新 / 索引已过期 / 索引需要重建），状态为过期或需要重建时旁边会出现「重建」按钮。左侧导航里的「索引」目前只显示「即将支持」——独立的索引视图尚未实现，索引状态与「重建」按钮都在笔记列表上方。

## 7. 标签、链接与图谱

- **标签**：在左侧第二栏「文档属性」里「添加标签」，或直接在 frontmatter 写 `tags:`。左侧「标签」列出全部标签与数量，点击即筛选；对当前文档的标签可以直接点 ✕ 移除。
- **链接**：支持维基链接与 Markdown 链接。左侧第二栏切到「链接」会显示当前文档的「出链」和「入链」（哪些笔记引用了它）。
- **图谱**：左侧「图谱」打开知识图谱。画布**上方有两行工具栏**：第一行是「N 篇笔记 / M 条连线」计数、节点上限、目录 / 标签 / 链接类型三个筛选框与「重置视图」；第二行是两个图例（孤立节点数、断链数）、「孤立节点」与「断链」两个开关，以及「重新布局」。方向键在节点间移动、回车打开、Esc 取消选择。

## 8. 每日笔记与模板

- **每日笔记**：侧栏顶部「新建每日笔记」打开当天的 `daily/YYYY-MM-DD.md`；已存在就直接打开，不存在则新建一篇**极简日记**——只有标题（`# 日期`）与一个待办列表项，用来随手记。要带小节结构的日记，用下面模板库里的「每日日记」（含今日焦点、时间安排、今日记录、今日复盘）。
- **模板**：侧栏「从模板新建」打开模板选择器。内置模板包括：每日日记、每周复盘、会议记录、学习笔记、读书笔记、实验记录、文献阅读、研究计划、测试用例、决策记录。
- 自己的模板：把 `.md` 文件放进知识库的 `templates/` 目录即可出现在列表里；与内置模板同名的用户模板会覆盖内置项。

## 9. 引用文献

- 把 `.bib`、`.ris` 或 CSL-JSON（数组形式的 `.json`）文件放在知识库**根目录**，左侧「引用文献」会自动加载。
- 搜索框提示为「搜索 key / 标题 / 作者 / 年份」；找到条目后点「插入引用 [@key]」把引用写到光标处。
- 左侧第二栏的「引用文献」列出当前文档用到的文献；找不到的 key 会标为「未在引用库中找到」；文件里有无法解析的条目会明确提示，而不是静默忽略。
- 导出时文末会生成编号的「参考文献」列表，条目形如 `作者 (年份) 标题. 期刊 卷(期) 页. doi:…`：年份用括号且后面不加句点，各段之间是空格而不是逗号，DOI 在能安全成链时是链接、否则显示为 `doi:` 文本。

## 10. 导出

- 设置 → 导出 →「导出（当前文档）」，五种格式：**导出 HTML**、**导出 PDF**、**导出纯文本**、**导出表格（CSV）**、**导出长图**（打开一篇文档后才可用）。
- **导出 HTML**：生成单个自包含文件（图片内联），可直接分享或发布。
- **导出 PDF**：打开系统打印对话框，选择打印机或「Microsoft Print to PDF」；「纸张大小」（A3 / A4 / A5 / Letter / Legal）与「页面方向」（纵向 / 横向）在设置里预先选好。
  - Linux 上这条路径依赖 WebKitGTK 自己开始打印。实测（WebKitGTK 2.52.6，见 `docs/DOC-AUDIT.md` §4）：`window.print()` 会被接受，但**既不弹对话框也不报错**。这种情况现在会明确告诉你「系统没有打开打印对话框」，并给出替代做法——先「导出 HTML」，再在浏览器里打印成 PDF。
- 「包含 Front Matter 元数据」控制导出是否带上 YAML 元数据块。

## 11. 历史版本、回收站与恢复

- **历史版本**：左侧第二栏的「历史版本」列出这篇文档的版本（每次保存前的快照；默认保留最近 10 个，设置 → 编辑器 →「历史版本上限」可改）。可以「恢复」，或「对比当前」查看差异并在差异视图里「恢复此版本」。
- **回收站**：左侧「回收站」列出删除的笔记，点「恢复」还原到原路径；「清空回收站」需要「确认清空」，之后不可恢复。
- **意外中断**：上次会话异常结束时，启动后会提示发现可恢复的临时文件；关闭窗口时若有未保存内容也会先询问。

## 12. 配置 AI

设置 → AI，从上到下依次是：

1. **服务商**：`openai` / `anthropic` / `gemini` / `grok` / `deepseek` / `local` / `custom`。
2. **接口地址（Base URL）**：七个服务商都显示并可以编辑这一项（默认 `http://localhost:1234/v1`，即本机模型服务，LM Studio / Ollama 等提供 OpenAI 兼容端点时填它们的地址）。
3. **模型**：直接输入模型名，或先点「刷新模型列表」拉取候选；切换服务商后列表会重新拉取。
4. **密钥（API Key）**：粘贴后点「保存 Key」。密钥加密保存在 Stronghold 库里，界面只显示掩码表示「已配置」，不会回读。
5. **调参**：「温度（采样随机性）」「最大输出 Tokens」「系统提示词」「笔记上下文长度（字符）」「允许本地/内网地址」（使用 localhost 或内网地址时需要保持开启）。
6. **思考深度**：跟随服务商默认 / 不思考（最快）/ 极简 / 低 / 中 / 高 / 极高（最慢）。越高越慢，但推理更充分。
7. **AI 修改文档的权限**：每次询问（推荐）/ 直接写入，不再询问 / 禁止 AI 写入文档。
8. **启用 AI 功能**：总开关。关闭后不发送任何请求，所有 AI 写入一律拒绝（权限设置会保留）。
9. **最近的 AI 活动**：AI 写入与拒绝的记录（时间、来源、种类、结果、说明），不含正文，可「清空记录」。

## 13. AI 的三种用法

- **续写**：在编辑器里按 `Tab`，出现灰色建议后，再按 `Tab` 接受、按 `Esc` 丢弃。没有配置模型或 Key 时不会发起请求。
- **聊天**：右侧信息栏「AI」页签（如果当前显示的是智能体面板，点其中的「回到聊天面板」）。可以追问、写稿、让它续写；打开「引用当前文档」会把当前笔记（或选区）作为上下文随消息发送，也可以「添加图片」；回答可以「插入到文档光标处」或复制。
- **选区改写**：选中文字后，在工具栏 ✨ 菜单里选「AI 改写」「润色」或「翻译」（翻译目标语言跟随界面语言）。
- 权限为「每次询问」时，AI 要写入文档会弹窗；「允许这一次」只放行当前这次，「本次运行内始终允许」只对该类写入生效（插入与替换选区是两类），重启后回到询问。

## 14. 外观与其它设置

设置页共八项：常规、外观、编辑器、导出、AI、插件、智能体、桌面宠物。

- **外观**：主题（浅色 / 深色 / 跟随系统）、配色方案（默认、暖阳、森林、海洋、樱花、薄雾、石墨、午夜、薰衣草、沙漠、薄荷、咖啡、梅子、暮色、绯红）、强调色（可「跟随系统强调色」）、界面字体 / 编辑器字体 / 等宽字体、字号、行高、高对比度、内容方向（自动 / 左到右 / 右到左）、**专注模式**。
- **编辑器**：打开文档时默认视图、自动保存间隔、历史版本上限、拼写检查、源码自动换行、源码行号、渲染任务列表勾选、分屏滚动同步、字数目标、状态栏词数、删除前二次确认。
- **导出**：导出当前文档（HTML / PDF / 纯文本 / 表格 CSV / 长图）与导出默认设置——纸张大小（A3 / A4 / A5 / Letter / Legal）、页面方向、页边距（毫米）、图片格式（PNG / JPG）与 JPG 质量、是否包含 Front Matter；下面还有导出预览。
- **常规**：知识库路径、语言（简体中文 / English）。
- **AI**：服务商、接口地址、模型、密钥、调参、思考深度、写入权限、总开关与「最近的 AI 活动」（详见 §12）。
- **插件**：列出当前知识库 `plugins/` 目录里的插件及其状态。出于安全策略，**发行版不会加载用户插件**（设置里有说明）；内置的 Callout / Status / FloatBox 始终可用。
- **智能体**：管理已注册的 ACP 程序，扫描本机可调用的程序，添加、更新或删除注册项，选择新会话使用的引擎；完全版另附带 OpenCode。程序需要真正支持 ACP 协议，只有可执行路径并不保证能连接。权限批准与已保存的 OpenCode 授权分开管理。
- **桌面宠物**：七个子页——常规与交互、角色与动画、气泡与消息、通知与声音、养成与统计、项目与多角色、高级与集成。

## 15. Git 同步与 SSH 远程工作区

- **Git 同步**：左侧「云同步」打开当前知识库的 Git 面板；尚未初始化时先初始化，填写并保存远端地址。输入提交信息后手动提交，再按需拉取或推送。拉取只允许快进，并要求工作区干净；冲突请在本机用 Git 处理。这里没有后台定时同步，Git 凭据由系统 Git / SSH 配置负责。
- **SSH 实时编辑**：在左侧「文件夹」菜单选择添加远程工作区，填写用户、主机、端口、服务器上的绝对目录与本地文件夹名。选择「实时」后通过本机 `sshfs` 挂载进知识库；编辑和保存直接作用于挂载目录，网络断开时先重连再继续。可在同一窗口断开挂载。
- **复制导入**：选择「复制」时使用本机 `rsync` 将远程目录复制进知识库；以后编辑的是本地副本，并非双向同步。当前远程工作区仅支持 SSH，不支持 FTP。
- **认证**：支持 SSH Agent / 系统配置、指定私钥文件或输入密码。密码不保存为连接配置；密码方式的复制导入还需要本机 `sshpass`。首次连接请核对服务器主机密钥。

## 16. 数据在哪、怎么备份

- 备份就是复制知识库文件夹：笔记、`<笔记名>_assets/`（粘贴进笔记的图片）、`attachments/`、`plugins/`、`templates/` 与引用文件都在里面；`.nekowite/`（索引、历史、插件治理）与 `.nekowite-trash/`（回收站）可以一起复制或忽略。
- API Key 不在知识库里；换电脑后需要重新在设置 → AI 里填写。
- 隐私细节：哪些数据会离开本机、存放在哪里、AI 权限如何工作，见 [PRIVACY.md](PRIVACY.md)。
